# Dino Run type game
# Proiectul constă într-un mediu 3D generat în timp real, unde utilizatorul controlează un obiect (un cub) prin intermediul intensității vocii. Scopul jocului este de a face cubul să "sară" pentru a evita obstacolele, transformând amplitudinea semnalului audio într-o variabilă de control pentru poziția verticală a obiectului.

## Instalare
Cerințe: Max/MSP/Jitter

## Utilizare
Deschide patch-ul proiectmax.maxpat în Max/MSP/Jitter
Folosim Casti
